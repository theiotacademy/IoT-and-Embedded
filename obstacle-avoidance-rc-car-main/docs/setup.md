# Setup Guide

## Requirements

- Arduino IDE
- Arduino Uno
- USB cable
- Required hardware components

## Arduino IDE Setup

1. Install Arduino IDE.
2. Connect Arduino Uno through USB.
3. Open:

   firmware/obstacle_avoidance_car/obstacle_avoidance_car.ino

4. Select:

   Tools → Board → Arduino Uno

5. Select the correct:

   Tools → Port

6. Click Upload.

## Serial Monitor

Open:

Tools → Serial Monitor

Set baud rate to:

9600

The firmware prints:

Front Distance: XX cm
Left: XX cm | Right: XX cm
