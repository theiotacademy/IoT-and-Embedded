# Pinout

## L298N Motor Driver

| Arduino Pin | L298N |
|-------------|-------|
| D5 | ENA |
| D7 | IN1 |
| D8 | IN2 |
| D6 | ENB |
| D9 | IN3 |
| D10 | IN4 |

## HC-SR04

| Arduino Pin | HC-SR04 |
|-------------|---------|
| D12 | TRIG |
| D11 | ECHO |

## Servo

| Arduino Pin | Servo |
|-------------|-------|
| D4 | Signal |

## Power

- Arduino powered through USB/battery
- Motors powered through motor-driver supply
- Arduino and motor driver must share GND
